# Contributing

Thanks for helping. Issues and pull requests are welcome at
[github.com/tulipfarm/huntsman](https://github.com/tulipfarm/huntsman).

## Before you open a pull request

- Open an issue first for anything bigger than a small fix, so we can agree on the approach.
- Keep changes focused; one topic per pull request.
- Run `gofmt -l .`, `go vet ./...` and `go test ./...`. For changes that touch rendering, also run
  `docker build --target test .`.
- Add or update tests for behaviour you change.
- Update the README or the relevant `README.md` / `SPEC.md` when behaviour or flags change.

## Benchmarks and datasets

- Benchmark changes: see [benchmark/README.md](benchmark/README.md). Don't commit raw results
  (`results.jsonl`, `raw.jsonl`); they are ignored on purpose.
- Dataset changes: the dataset in `dataset/huntsman-v1/data/` is generated by its pipeline. Change the pipeline or
  `quotas.yaml` and regenerate, rather than editing the CSV by hand. Report bad rows (wrong snippet, dead page) as an
  issue with the row `id`.
